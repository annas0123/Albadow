# YouTube Tools

A premium dark-themed YouTube tools website with 3 main tools:
- **Video Downloader** — Download videos in multiple qualities (720p, 1080p, 4K)
- **Audio Downloader** — Extract audio as MP3 (128kbps, 192kbps, 320kbps)
- **Thumbnail Downloader** — Download thumbnails in all resolutions

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React + Vite + Tailwind CSS |
| Backend | Vercel Serverless API Routes (Node.js) |
| YouTube Data | cobalt.tools API + Direct Thumbnail Parsing |
| Hosting | Vercel |

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
